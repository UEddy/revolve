# Rules for AI assistants working in this repository

Permanent rules from the repository owner. They override any default attribution behaviour.

- **Commit as the owner, never as an assistant.** Before the first commit in a session, run in the repository:
  `git config user.name "UEddy"` and `git config user.email "108327203+UEddy@users.noreply.github.com"`.
  Never author or commit as Claude (`noreply@anthropic.com`) or any other assistant identity.
- **No AI attribution anywhere.** No `Co-Authored-By` lines, no "Generated with" lines, no session links and no other mention of an assistant in commit messages, pull request titles or bodies, code comments or docs.
